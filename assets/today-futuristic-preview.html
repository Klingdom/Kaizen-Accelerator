Design Notes — Luminous Constraint (Preview)

  • Typography trio: Instrument Serif (display) + Geist (body) + Geist Mono (numerals). Instrument Serif's optical warmth in "Thursday" headline contrasts the sterile precision of Geist Mono in time rails and numeric labels.
  • Cadence Pressure Ring (top-right of header): SVG arc divided into project/comm/CI segments proportional to planned minutes. Hover for breakdown tooltip. This pattern does not exist in any competing calendar product. It compresses the 4-2-2 constraint into one 56px token.
  • Block fills: 3-stop inner-top-light gradients — lighter top (highlight) → body fill → darker bottom (shadow). Combined with a top inner glow via inset 0 1px 0 rgba(255,255,255,0.22), blocks feel spatially lit rather than flat-painted.
  • Now-line: 2px with box-shadow: 0 0 12px 2px var(--now-glow). The glassy timestamp pill uses backdrop-filter: blur(8px). Dot animates on a 4s sine via nowPulse — the only persistent ambient animation on the page.
  • PROPOSED blocks (CI block + Comm block after lunch): retain dashed border encoding from Iter 29 locked decision. Add a gentle proposedShimmer brightness pulse at 2.2s — communicates "pending" without being distracting.
  • Kaizen two-ring ping (M3): the CI block fires kaizenRing at 900ms post-load — two concentric ring expansions from the block's boundary. Disciplined, not flashy.
  • IN_PROGRESS block (Q3 Roadmap Deck, 11:15–12:30): double outline ring — outer outline at 60% white opacity + inner ::before border at 35% — gives it a "currently active" halo without animation.
  • Glassmorphism: background: rgba(255,255,255,0.72); backdrop-filter: blur(24px) saturate(160%) on the cycle card. The 1px border uses rgba(255,255,255,0.65) which reads as an inner highlight in light mode.
  • Customization: Theme (light/dark), Palette (Phil's CI / Monochrome Operator), and Motion (full/reduced) all controlled via data-* attributes on <html>. Zero JavaScript variable mutations — pure CSS token switching. Try all combinations.
  • Hour rail texture: repeating-linear-gradient hairlines every 60px align with hour boundaries without explicit DOM elements. Current hour label is in --now-red; past hours at 45% opacity.
  • Motion reduced: Clicking "Reduced" disables all animation keyframes via [data-motion="reduced"] selector. Also respects prefers-reduced-motion: reduce OS setting.
