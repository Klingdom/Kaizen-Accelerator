Design Rationale — Chartered Minimalism

Typography Delta
DM Serif Display on the date heading ("Thursday, 30 April") replaces the system-font h1. The editorial weight anchors the page in a specific, real day — it says plan, not dashboard. DM Mono replaces system fonts for all numeric/time display (09:47, 10:00–12:00, bucket values). Current production uses generic system fonts for both. The monospace choice makes tabular numerals guaranteed — no layout shift as time changes.
Block Fill Delta
Current: flat #16a34a, #ca8a04, #9333ea. Proposed: 135deg linear gradients (lighter-top to base-bottom) that simulate directional light. The effect is subtle — Phil's color identity is preserved — but the blocks feel material rather than painted. PROPOSED blocks use the pale tint gradient (already in use as --*-bg variables) with a dashed border. The dashed encoding is preserved per Iter 29.
Spatial Delta
The bucket summary moves from below the grid to a right-margin annotation strip (164px column). This is the most significant layout change — it treats the three bucket bars as margin glosses alongside the schedule, similar to editorial annotations. On mobile, the strip collapses to a 3-column row below the grid. The hour rail narrows from 56px to 48px; its background shifts to --surface-2 (warm light gray) to create a recessed channel effect without a heavy border.
Now-Line Delta
Current: 2px red line + 8px dot. Proposed: 1.5px line + breathing glow trail (fades right) + timestamp label (09:47 in DM Mono, red). The glow pulses at 3s intervals via CSS-only keyframes affecting opacity only (compositor-thread safe). The dot scales 1→1.3→1 on the same cycle. Together: the now-line becomes the page's heartbeat — present but not loud.
Dialog Delta
The BlockDetailDialog gains a bucket color bar at the top (4px gradient stripe matching the block's bucket fill). The title uses DM Serif Display, giving the dialog a moment of editorial emphasis. All labels use DM Mono in uppercase — treating the data fields as structured record entries. The panel has a spring-physics entrance animation (cubic-bezier(0.34, 1.56, 0.64, 1)) that settles rather than slides — it feels purposeful.
Motion Signature
On page load, blocks cascade in from left with 60ms stagger per block (8px translateX + opacity). The kaizen chip on any linked block receives a single purple glow ring ping (800ms delay, fires once). This marks "this work is connected to improvement" without a tooltip or label. It is BAM-X's most distinctive motion moment — understated for continuous-improvement professionals who recognize kaizen linkage.
