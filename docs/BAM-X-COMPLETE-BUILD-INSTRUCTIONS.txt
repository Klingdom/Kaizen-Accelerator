### js/core/state.js

Create StateManager class that:
- Manages all application state in a single object
- Persists to localStorage as 'bam-x-state'
- Implements observer pattern with subscribe/notify
- Initial state includes: intentions[], schedule{mon/tue/wed/thu/fri: {deep/comm/ci: []}}, user{name, initials}, agents[], metrics{focusLevel, decisionConfidence, energy, interrupts}, currentPhase, currentDay
- Intention structure: {id, name, outcome, estimatedHours, priority, phaseAffinity, dependencies, state (backlog/planned/active/blocked/completed), scheduledDay, scheduledPhase, progress, createdAt, updatedAt}
- Methods: addIntention(), updateIntention(), deleteIntention(), getIntention(), getBacklogIntentions(), getScheduledIntentions(day, phase)
- Schedule methods: scheduleIntention(id, day, phase), unscheduleIntention(id)
- Capacity calculation: getCapacity() returns {total: 40h, allocated, remaining, percentage, byPhase{deep/comm/ci: {allocated, capacity, percentage}}}
- Helper methods: generateId(), getMonday(), getFriday(), getCurrentDayKey(), formatDate()
- Export/import: exportData(), importData(), reset()
- Auto-save on every state change

### js/core/rhythm.js

Create RhythmManager class that:
- Defines 4-2-2 rhythm: phases array with {name, label, duration (minutes), color, protection level}
- Deep Work: 4h, #3b82f6, protection 0.95
- Communication: 2h, #10b981, protection 0.3
- Continuous Improvement: 2h, #8b5cf6, protection 0.5
- Start time: 08:00
- Methods: start() begins 1-minute timer, stop() clears timer
- getCurrentPhase() calculates which phase we're in based on current time, returns {name, index, elapsed, remaining, progress}
- updateCurrentPhase() checks for transitions and triggers events
- getPhaseAtTime(minutes), getTimelinePosition() for cursor
- formatMinutes(), formatDuration() for display
- getNextPhaseInfo() returns next phase and time until it starts
- shouldAllowInterrupt(urgency) compares to current protection level
- getPhaseSchedule() returns array of phases with start/end times
- Emits 'phaseTransition' events when phases change

### js/core/agents.js

Create AgentManager class that:
- Manages four AI agents from state
- Planning Agent: generatePlan() that sorts intentions by priority, allocates across week using allocateIntentions(), getBestPhase() heuristics (deep for analysis/design, comm for meetings, ci for planning), returns plan with confidence
- applyPlan(plan) schedules all intentions
- Momentum Agent: detectBlockers() finds unmet dependencies, suggestNextAction() recommends what to work on now based on current day/phase
- Context Agent: findRelevantContext(intentionId) simulates retrieving similar work, docs, conversations
- Reflection Agent: analyzeSprintHealth() calculates capacity utilization, completion rate, generates recommendations (over-allocated, under-allocated, low deep work usage)
- generateInsight() returns random insight string for AI personality
- All methods use state manager to read/write data

## CRITICAL IMPLEMENTATION DETAILS

1. **State Persistence**: Every state change must call saveState() which writes to localStorage
2. **Observer Pattern**: Components subscribe to state changes and re-render automatically
3. **Drag and Drop**: Use HTML5 drag API with data-intention-id attributes
4. **Time Updates**: Rhythm manager runs setInterval every 60 seconds, dashboard updates display every 1 second
5. **Phase Transitions**: Emit custom 'phaseTransition' event, components listen and update
6. **Capacity Tracking**: Calculate in real-time by summing hours from scheduled intentions
7. **AI Plan Generation**: Sort by priority (critical>high>medium>low), then allocate to best phase, prefer early days for high priority
8. **Gradient SVG**: Use linearGradient with id="gradient" for progress ring
9. **Color Coding**: Intentions use priority colors, phases use distinct colors
10. **Responsive Grid**: Container uses CSS Grid with 380px|1fr|380px columns
11. **No Dependencies**: Pure vanilla JavaScript, no frameworks or build tools
12. **Progressive Enhancement**: Works without JavaScript for basic viewing
